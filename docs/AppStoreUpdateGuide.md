# App Store アップデート手順書

このガイドは、沖ドキ！計算ツールのApp Storeアップデート手順をまとめたものです。

---

## 1. 事前準備（コード変更）

### バージョン番号の更新

`MyFirstApp.xcodeproj/project.pbxproj` ファイル内の以下の項目を更新します。

| 項目 | 説明 | 例 |
|------|------|-----|
| `MARKETING_VERSION` | ユーザーに表示されるバージョン番号 | 1.0.1 → 1.0.2 |
| `CURRENT_PROJECT_VERSION` | 内部ビルド番号（毎回インクリメント） | 2 → 3 |

#### 更新箇所

project.pbxproj内で、Debug と Release の両方の設定を更新する必要があります。

```
/* Debug */
CURRENT_PROJECT_VERSION = 3;
MARKETING_VERSION = 1.0.2;

/* Release */
CURRENT_PROJECT_VERSION = 3;
MARKETING_VERSION = 1.0.2;
```

**注意**:
- `MARKETING_VERSION` は同じバージョンでも、ビルドを再アップロードする場合は `CURRENT_PROJECT_VERSION` を上げる必要があります
- App Store Connect では、同じバージョン番号でも異なるビルド番号であれば新しいビルドとして認識されます

### プロジェクトの言語設定

開発言語は `developmentRegion = ja;` で設定されています（変更不要）。

## 2. ビルド確認

### シミュレータでのテスト

アーカイブ前に、シミュレータでビルドが通ることを確認します。

```bash
xcodebuild -project MyFirstApp.xcodeproj -scheme MyFirstApp -destination 'platform=iOS Simulator,name=iPhone 17' build
```

成功すると「BUILD SUCCEEDED」と表示されます。

---

## 3. Xcodeでのアーカイブ作成

### 手順

1. **デバイス設定を変更**
   - Xcodeのツールバーで実行先を「Any iOS Device (arm64)」に変更
   - シミュレータのままではArchiveメニューが無効のため

2. **アーカイブを作成**
   - メニュー: `Product` → `Archive`
   - ビルドが開始され、完了するとOrganizerが自動で開く

3. **Organizerの確認**
   - 作成されたアーカイブが一覧に表示される
   - バージョン番号とビルド番号が正しいことを確認

---

## 4. App Store Connectへのアップロード

### 手順

1. Organizerで対象のアーカイブを選択

2. **「Distribute App」をクリック**

3. **配布方法を選択**
   - 「App Store Connect」を選択
   - 「Upload」を選択

4. **オプション設定**
   - デフォルト設定のまま「Next」で進む
   - コード署名が自動で行われる

5. **アップロード実行**
   - 「Upload」をクリック
   - 完了まで待機（数分かかる場合あり）

### アップロード完了の確認

- Xcode: 「Upload Successful」と表示される
- App Store Connect: 「TestFlight」タブの「ビルド」に新しいビルドが表示される
  - 処理中は「処理中」ステータス
  - 準備完了後、選択可能になる

---

## 5. App Store Connectでの設定

### 新バージョンの作成

1. [App Store Connect](https://appstoreconnect.apple.com/) にログイン

2. 対象アプリを選択

3. **新バージョンを追加**
   - 左メニュー「iOSアプリ」の横にある「+」をクリック
   - ストアのバージョン番号を入力（例: 1.0.2）
   - 「作成」をクリック

### ビルドの選択

1. 「ビルド」セクションで「ビルドを追加」をクリック
2. アップロードしたビルドを選択
3. 「終了」をクリック

### What's New（このバージョンの最新情報）の入力

アップデート内容を日本語で記載します。

```
【更新内容】
・〇〇機能を追加しました
・△△の不具合を修正しました
・パフォーマンスを改善しました
```

### 輸出コンプライアンス情報

ビルド選択後、輸出コンプライアンスについて質問されます。

**このアプリの場合**:
- 暗号化: 標準のHTTPS通信のみ使用
- 質問「アプリで暗号化を使用していますか？」→「いいえ」を選択

---

## 6. 審査提出

### 手順

1. すべての必須項目が入力されていることを確認
   - アプリ情報
   - ビルド
   - What's New
   - 輸出コンプライアンス

2. 右上の「審査に追加」をクリック

3. 確認画面で「審査に提出」をクリック

### 審査期間

- 通常: 1〜2日
- 状況により変動あり
- ステータスは App Store Connect で確認可能:
  - 「審査待ち」→「審査中」→「承認済み」

### 審査後の公開

- 自動公開: 審査通過後、自動的に公開される（デフォルト設定）
- 手動公開: 設定で変更可能

---

## 7. 補足情報

### プライマリ言語の確認

App Store Connect → アプリ情報 → 一般情報 → プライマリ言語

### デベロッパ名の変更

デベロッパ名（App Storeに表示される名前）を変更するには:

1. [Apple ID アカウント](https://appleid.apple.com/) にログイン
2. 「サインインとセキュリティ」または「個人情報」セクション
3. 名前を変更
4. App Store Connect に反映されるまで時間がかかる場合あり

### スクリーンショットの更新

UIに変更がある場合はスクリーンショットも更新が必要です。
詳細は [ScreenshotGuide.md](./ScreenshotGuide.md) を参照。

## トラブルシューティング

### ビルドがApp Store Connectに表示されない

- アップロード後、処理に数分〜数十分かかることがあります
- メールで処理完了の通知が届く場合もあります

### 審査でリジェクトされた場合

1. App Store Connect で理由を確認
2. 問題を修正
3. ビルド番号を上げて再アップロード
4. 再審査を提出

### ビルド番号の重複エラー

同じビルド番号のアーカイブはアップロードできません。
`CURRENT_PROJECT_VERSION` を必ずインクリメントしてください。
