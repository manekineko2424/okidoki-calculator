# 天国定義仕様書（有料版機能）

## 概要

ユーザーが「天国」の条件を定義し、入力された当選G数が条件に合致した場合に🟡🔵バーを自動配置する機能。
あくまでアシスト機能であり、ユーザーは手動でバー位置を変更可能。

## 天国の基本定義

- **天国判定**: 前回当選からの当選G数が **1〜32G以内** → 天国
- **連数**: 初当たり(1) + 天国当選回数（例: 初当たり + 天国1回 = 2連）

## 2連時の判定 - 離散値セット方式

ユーザーが1〜32Gの各G数を個別に選択して定義:

- **切断濃厚**: 選択したG数で当選 → 🔵バー移動
- **継続（またぎ）**: 選択したG数で当選 → 🟡バー移動
- **未選択**: 判定なし（バー移動しない）

### 特徴
- 飛び飛びの値も設定可能（例: 1G, 5G, 16G, 32G）
- 連続範囲である必要はない
- BIG/REGそれぞれ別々に設定

### データモデル

```swift
struct TwoChainCondition: Codable {
    var bigCutGs: Set<Int>        // BIG: 切断濃厚と判定するG数
    var bigContinueGs: Set<Int>   // BIG: 継続と判定するG数
    var regCutGs: Set<Int>        // REG: 切断濃厚と判定するG数
    var regContinueGs: Set<Int>   // REG: 継続と判定するG数
}
```

### 参考プリセット

| 機種 | BIG切断 | BIG継続 | REG切断 | REG継続 |
|------|---------|---------|---------|---------|
| ブラック/ゴージャス | 1-17G | 18-32G | 1-14G | 15-32G |
| ゴールド | 1-18G | 19-32G | 1-15G | 16-32G |

※ プリセットは参考値。読込後もユーザーが自由に編集可能
※ 初期状態は全て未選択（判定なし）

## 3連以上の判定

### 仕様
- **当選G数**: 常に1〜32G（天国定義と共通、条件ごとに変えない）
- **条件タイプ**: 枚数範囲 or 連数以上
- **判定**: 切断濃厚 or またぎ

### 条件タイプ

| タイプ | 説明 |
|--------|------|
| 枚数範囲 | 出玉がX〜Y枚の場合に適用 |
| 連数以上 | X連以上の場合に適用 |

### データモデル

```swift
enum ConditionType: Codable, Equatable {
    case payoutRange(min: Int, max: Int)
    case chainCountOrMore(count: Int)
}

struct ChainCondition: Codable, Identifiable {
    let id: UUID
    var conditionType: ConditionType
    var judgment: BarJudgment  // .cut or .continuation
}
```

### ユーザー定義例

| 条件 | 判定 |
|------|------|
| 1000〜1500枚 | 切断濃厚 |
| 1500〜2000枚 | またぎ |
| 3連以上 | 切断濃厚 |
| 5連以上 | またぎ |

※ 条件は上から順に評価、最初に合致したものを適用

## バー自動配置

### フロー

1. ユーザーがhit行のG数を入力
2. onChangeまたはonSubmitで判定トリガー
3. 連数計算 → 判定
4. 切断濃厚 → 🔵バー移動 / 継続 → 🟡バー移動
5. UIにバー位置が反映される
6. ユーザーは必要に応じて手動調整可能

### 判定結果

```swift
enum JudgmentResult {
    case cut           // 切断濃厚 → 🔵バー移動
    case continuation  // 継続（またぎ）→ 🟡バー移動
    case none          // 条件不一致 → バー移動なし
}
```

## UI設計

### 天国設定画面

- 天国判定G数: 1〜32G（編集可能）
- 2連時判定: BIG/REG別にG数を個別選択
- 3連以上条件: リスト形式で追加/編集/削除
- バー自動配置: ON/OFFスイッチ
- プリセット読込: 機種別の参考値を適用
