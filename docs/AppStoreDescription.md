## 説明文（4000文字以内）

```
パチスロ「沖ドキ！」シリーズの有利区間ゲーム数をリアルタイムで自動計算するツールです。

【主な機能】
- ボーナス当選時のG数を記録するだけで、有利区間の残りゲーム数を自動計算
- RB・BB・最終ボーナスの内部加算を自動で反映
- 天国状態（OK）の判定を自動表示
- 複数のリセット位置を履歴で視覚的に管理

【対応機種】
- 沖ドキ！ブラック（RB+24G / BB+59G / 上限2000G）
- 沖ドキ！ゴールド（RB+29G / BB+69G / 上限2000G）
- 沖ドキ！ゴージャス（RB+24G / BB+59G / 上限3000G）
- カスタム設定（任意の加算値・上限値を設定可能）

【使い方】
1. 下部のタブから機種を選択
2. ボーナス当選時にG数を入力
3. 種別ボタン（RB/BB/最終）をタップ
4. 残りG数が自動で計算・表示されます

【特徴】
- シンプルな操作で素早く記録
- 手計算の手間を完全に削減
- 複数のリセット地点を同時管理
- データは端末内のみに保存（サーバー送信なし）
- 広告なし・完全無料

実戦中の有利区間管理にぜひご活用ください。
```
