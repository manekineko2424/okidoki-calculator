## 説明文（4000文字以内）

```
パチスロの有利区間ゲーム数を簡単に計算・管理できるツールです。

【主な機能】
- 現在の有利区間ゲーム数をリアルタイム計算
- RB/BB当選時の自動加算
- リセット位置・カット位置の設定
- 天国状態の判定表示
- 複数機種対応（ブラック/ゴールド/ゴージャス）

【使い方】
1. 機種を選択
2. 「+RB」「+BB」ボタンで当選を記録
3. 現在G数を入力
4. 残りG数と状態が自動計算されます

【特徴】
- シンプルで使いやすいインターフェース
- 広告なし・完全無料
- オフラインで動作
- データは端末内に保存

※ 本アプリはパチスロ遊技の補助ツールです。ギャンブル依存症にご注意ください。
```

## スクリーンショット取得手順

### 必要なサイズ
1. **iPhone 6.9"** (1320 x 2868px) - iPhone 17 Pro Max
2. **iPhone 6.7"** (1290 x 2796px) - iPhone 15/16 Pro Max

### 取得方法
1. Simulatorでアプリを起動
2. ⌘+S でスクリーンショット保存
3. 以下の画面を撮影：
   - メイン画面（機種選択状態）
   - 入力中の画面
   - 計算結果表示画面

## 審査時の注意事項

### ギャンブル関連アプリ
- 年齢制限は必ず17+に設定
- 説明文にギャンブル依存症への注意喚起を含める
- 実際のギャンブル機能（賭け）がないことを明確に

### 商標について
- 「沖ドキ」はメーカー商標の可能性
- App Store名では使用を避け、キーワードのみで対応
- アプリ内での使用も検討が必要
