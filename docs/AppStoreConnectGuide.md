## App Store Connect 設定手順

### ステップ1: 新規アプリ作成
1. https://appstoreconnect.apple.com にアクセス
2. 「マイApp」→「＋」→「新規App」
3. 以下を入力:
   - プラットフォーム: iOS
   - 名前: `沖ドキ！有利区間ゲーム数計算ツール`
   - プライマリ言語: 日本語
   - バンドルID: `dev.manekineko.MyFirstApp`
   - SKU: `okidoki-calculator-001`（任意の一意識別子）

### ステップ2: アプリ情報を入力
**「App情報」タブ:**
- カテゴリ: ユーティリティ（プライマリ）、エンターテインメント（セカンダリ）
- プライバシーポリシーURL: [GitHub Pages等で公開したURL]
- 年齢制限: 17+（ギャンブル関連コンテンツ）

### ステップ3: バージョン情報を入力
**「iOS App」タブ → バージョン情報:**

| 項目 | 入力内容 |
|-----|---------|
| スクリーンショット | 撮影済み画像をアップロード |
| プロモーションテキスト | 下記「コピー用テキスト」参照 |
| 説明 | 下記「コピー用テキスト」参照 |
| キーワード | 下記「コピー用テキスト」参照 |
| サポートURL | （GitHubリポジトリURLなど） |
| バージョン | 1.0 |
| 著作権 | © 2026 manekineko |

### ステップ4: ビルドをアップロード
```bash
# Xcodeでアーカイブ（GUI推奨）
# Product → Archive → Distribute App → App Store Connect
```

または、コマンドラインで:
```bash
# アーカイブ作成
xcodebuild -project MyFirstApp.xcodeproj -scheme MyFirstApp \
  -archivePath build/MyFirstApp.xcarchive archive

# App Store Connect にアップロード
xcodebuild -exportArchive -archivePath build/MyFirstApp.xcarchive \
  -exportPath build/Export -exportOptionsPlist ExportOptions.plist
```

### ステップ5: 審査提出
1. 「審査用に追加」でビルドを選択
2. 輸出コンプライアンス: 暗号化なし
3. コンテンツ権利: 確認
4. 「審査に提出」

## 注意事項

### 商標について
「沖ドキ」はユニバーサルエンターテインメントの登録商標です。
- 審査でリジェクトされた場合は、アプリ名を「有利区間ゲーム数計算ツール」に変更
- キーワードには使用可能な場合が多い

### 年齢制限
17+の理由を審査ノートに記載することを推奨:
> 本アプリはパチスロの有利区間ゲーム数を計算する補助ツールです。実際の賭け機能はありません。

## コピー用テキスト

### 説明文
```
パチスロ「沖ドキ！」シリーズの有利区間ゲーム数をリアルタイムで自動計算するツールです。

【主な機能】
- ボーナス当選時のG数を記録するだけで、有利区間の残りゲーム数を自動計算
- RB・BB・最終ボーナスの内部加算を自動で反映
- 天国状態（OK）の判定を自動表示
- 複数のリセット位置を履歴で視覚的に管理

【対応機種】
- 沖ドキ！ブラック（RB+24G / BB+59G / 上限2000G）
- 沖ドキ！ゴールド（RB+29G / BB+69G / 上限2000G）
- 沖ドキ！ゴージャス（RB+24G / BB+59G / 上限3000G）
- カスタム設定（任意の加算値・上限値を設定可能）

【使い方】
1. 下部のタブから機種を選択
2. ボーナス当選時にG数を入力
3. 種別ボタン（RB/BB/最終）をタップ
4. 残りG数が自動で計算・表示されます

【特徴】
- シンプルな操作で素早く記録
- 手計算の手間を完全に削減
- 複数のリセット地点を同時管理
- データは端末内のみに保存（サーバー送信なし）
- 広告なし・完全無料

実戦中の有利区間管理にぜひご活用ください。
```

沖ドキ,パチスロ,有利区間,ゲーム数,計算,ツール,ブラック,ゴールド,ゴージャス,天国

ボーナス当選時のG数を記録するだけで、有利区間の残りゲーム数をリアルタイムで自動計算。沖ドキ！ブラック・ゴールド・ゴージャスに対応。

## 審査ノート（推奨）
```
本アプリはパチスロ「沖ドキ！」シリーズの有利区間ゲーム数を計算する補助ツールです。

実際の金銭的な賭けを行う機能はなく、ゲーム数の記録と計算のみを行います。
データはすべてユーザーの端末内に保存され、サーバーへの送信は行いません。

年齢制限を17+に設定した理由：
パチスロ関連のコンテンツであるため、成人向けとしています。
ただし、アプリ自体にギャンブル機能は一切含まれていません。
```
